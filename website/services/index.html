How it works

  1. Put your drawings in

    Upload PDF or image plans for each level, then set the scale with two taps.

  2. Mark up as it goes in

    Add outlets, boards, pits and racks. Draw each cable or pipe, connect its ends and pick the port it lands on.

  3. Check, test and photograph

    Run the checklist on each item, record test results and add photos before the wall or trench closes.

  4. Hand it over

    Print the handover pack, as-builts, schematics and port schedules. Everything is already in them.
